# Batch Generation Best Practice

For long character or environment bibles (especially historical/live-action aesthetics like 1970s Giallo), generate pages in **batches of 3** instead of all at once.

## Recommended Batches

**Batch 1 (Foundation)**
- Page 01: Primary Reference
- Page 02: Orthographic Turnaround
- Page 03: Morphology & Silhouette

**Batch 2 (Details)**
- Page 04: Expressions & Emotion
- Page 05: Cranial & Appendage Details
- Page 06: Surface Treatment

**Batch 3 (Final)**
- Page 07: Props & Accessories
- Page 08: Materials, Color & Motion

## Why This Works Better

- Allows visual consistency review between batches
- Reduces identity drift
- Gives user opportunity to correct direction mid-process
- Matches observed user preference for controlled pacing

## Environment Bibles

Apply the same batch-of-3 approach when creating location bibles. Present each batch and wait for user confirmation before continuing.
