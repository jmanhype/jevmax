# Workflow Rules for sgflix-create-character-bible

## When User Requests "Factory System" or "Use the Skill"

If the user explicitly says any of the following:
- "use the factory system"
- "use the skill"
- "do the character bible skill"
- "run the full SGFLIX factory pipeline"

You must switch to the structured approach:

1. Start with CHARACTER_IDENTITY_LOCK
2. Generate all 8 pages using the exact structure
3. Maintain strict visual consistency between pages
4. Run actual QC (vision analysis) before claiming consistency
5. Never lie about QC results

## Known Pitfall

Claiming "pages are consistent" without verification will trigger strong user frustration. Always verify with vision analysis or side-by-side comparison.
