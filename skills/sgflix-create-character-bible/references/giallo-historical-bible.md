# Giallo / Historical Aesthetic Bible Creation

**Session:** 2026-05-20 — Vittorio Rossi (Black-Gloved Killer)

## Workflow Used
- User said "up to you" → Agent proposed strong archetypal character (Vittorio Rossi) with clear visual hooks (black leather gloves, turtleneck, 70s Italian elegance).
- Full 8-page Character Bible generated in 3 batches of ~3 pages each for better identity consistency.
- Environment Bible started immediately after in same batch style.

## Key Adaptations for 1970s Italian Giallo
- Heavy emphasis on 35mm film grain, saturated reds/blacks, baroque architecture.
- Signature props locked early (leather gloves, knives).
- Prompts consistently reference Argento/Bava, voyeuristic framing, and "wrongness" of stylish campy violence.
- Batch size: 3 pages per call for optimal consistency vs speed.

## Recommended Batch Order
1. Pages 01–03 (Primary, Turnaround, Morphology)
2. Pages 04–06 (Expressions, Details, Surface)
3. Pages 07–08 (Props, Materials/Color)

## Environment Bible
Environment bibles for Giallo projects follow the same batch approach. Focus on:
- Baroque palazzos and decaying luxury interiors
- Strong shadow play and lurid color
- Multiple angles of key murder locations

## Lesson
When user gives creative freedom ("up to you"), propose one clear, high-signal character concept and move directly into bible generation rather than asking for more details.
