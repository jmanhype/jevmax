## 3. Concept gate

Run the judgment gate before any render.

Record:

- hook score
- brand fit
- survival odds
- total score
- token usage
- rejected concepts and reason

Select up to eight concepts. Do not render unranked concepts.

## 4. Production route

Default:

```text
GPT Image 2.5 Sunburst style board: 0 credits while promotion is active
V6 720p 5-second no-audio video: 40 credits each
```

Projected eight-video media cost:

```text
8 x 40 = 320 credits
```

Premium alternatives require explicit approval:

- MiniMax H3 768p: measured 150 credits per 5-second video
- Seedance 2.5 1080p: measured 850 credits per 5-second video

## 5. Render controls

- Use the approved seed image for every variant.
- Freeze the character block verbatim.
- Use one continuous 5-second take unless the client approves multi-shot work.
- Require no readable text, card, logo, UI, or caption unless a locked plate was approved.
- Record model, quality, duration, seed, task ID, credits, and output path.
- Keep failed tasks in the log.

## 6. QA gates

For every delivered video:

- [ ] local file exists
- [ ] resolution and aspect match
- [ ] duration matches
- [ ] identity held
- [ ] product remained legible
- [ ] no unintended text or logo
- [ ] no extra people or products
- [ ] no unintended style shift
- [ ] audio state recorded
- [ ] credits reconciled
